# Changelog — Moonlighter Floor Forge

## 0.5.0 (2026-11-14)

- Новая GM-панель «Рынок»: 5 категорий спроса, смена рыночного дня и общий для игрового мира статус спроса.
- Оценка стоимости предметов по базовой цене D&D 5e и коэффициенту спроса; для предметов без цены — явные ориентировочные оценки.
- Интеграция с Item Piles для создания торговца с ассортиментом, выбранным из мировых предметов. Отдельные копии предметов получают цену на момент создания.
- Настройки наценки, количества товаров, позиции токена, названия магазина и папки предметов.
- Оригиналы предметов и уже заполненные сундуки не изменяются. Сохранены все возможности v0.4.
- Добавлены тесты расчётов рынка и адаптера торговца, синтаксические проверки.
- **Ограничение:** автоматического слежения за сделками, переоценки существующих торговцев и расчёта цены игроком продаваемого лута пока нет.

# История версий Moonlighter Floor Forge

## 0.4.0 — 14 ноября 2026

- Опциональная поддержка **Item Piles** и **Item Piles: D&D 5e** для Foundry v13.
- Новые сундуки по API `createItemPile` с собственными инвентарями для игроков.
- Режим добычи «Авто / Item Piles / Старые тайники»; совместимость без Item Piles сохранена.
- Контейнеры Item Piles не получают вторую копию лута в флагах Moonlighter; выключена прежняя выдача для таких сундуков.
- Панель ведущего показывает их состояние и открывает интерфейс Item Piles.
- Однокнопочная конвертация неполученных сундуков, с защитой от повторного импорта.
- Проверки адаптера API, мок-генерации с обоими режимами и геометрии.

## 0.3.0

- Экспедиции на несколько этажей, секреты, типы комнат, блокировка боевых дверей, сундуки GM.

## 0.2.0

- Библиотека размеченных комнат, стыковка дверных проёмов и перенос препятствий.

## 0.1.0

- Первичная генерация NPC и добычи для готовых карт.
