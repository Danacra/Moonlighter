# Moonlighter Floor Forge v0.9.2

**Foundry VTT v13 / D&D 5e.** Генератор подземелий с отдельным арт-прототипом **Golem Dungeon**.

Режим Golem Dungeon позволяет загрузить утверждённую иллюстрацию комнаты (12 × 8 клеток) через встроенный File Picker и создать один зал либо два зала с четырьмя парами телепортов и настоящими стенами. Художественная иллюстрация пока предоставляется **отдельно от модуля** и загружается в Foundry через браузер.
