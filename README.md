# Moonlighter Floor Forge v0.9.0

Генератор подземелий в стиле Moonlighter для **Foundry VTT v13** (D&D 5e). Теперь включает безопасный источник перед боссом, мини-босса, опасные залы, декоративные ассеты и сундуки, открывающиеся после боёв.

## Установка по ссылке (без доступа к файлам)

Открой **Foundry Setup → Add-on Modules → Install Module** и вставь:

```text
https://raw.githubusercontent.com/Danacra/Moonlighter/main/module.json
```

Чтобы обновить существующий модуль: **Add-on Modules → Check for Updates**.

Прямая страница релиза: https://github.com/Danacra/Moonlighter/releases/tag/v0.9.0

## Проверка

В новом мире создай этаж **Procedural Tiles 0.9** (12 комнат, сетка 4×4, промежуток 4 клетки). Вход отмечен руной «ВХОД». Порталы — светящиеся арки. Перед боссом должна располагаться комната с источником, мини-босс встретится на пути, а сундуки в боевых комнатах будут скрыты до победы.

[Документация на русском](moonlighter-floor-forge/README_RU.md) · [Изменения](moonlighter-floor-forge/CHANGELOG.md)

Перед установкой сделай резервную копию мира. Сборка протестирована автоматически, но ещё не проверена в живой игре Foundry.
