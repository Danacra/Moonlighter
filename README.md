# Moonlighter Floor Forge v0.9.1

Процедурный генератор подземелий для Foundry VTT v13 (D&D 5e).

**Изменения 0.9.1:** новый оригинальный SVG-тайлсет, модульные стены фиксированного размера, каменные углы, разные палитры пола и тематический декор вместо одних ваз. Крупные объекты создают настоящие преграды для движения; проходы между комнатами, источник и Item Piles сохранены.

## Установка и обновление

В Foundry Setup → Add-on Modules установи/обнови модуль по манифесту:

```text
https://raw.githubusercontent.com/Danacra/Moonlighter/main/module.json
```

[Релиз v0.9.1](https://github.com/Danacra/Moonlighter/releases/tag/v0.9.1)

После обновления перезапусти Foundry, нажми Ctrl+F5 и **создай новый этаж** в Procedural Tiles, чтобы появился новый декор.

[Полная инструкция (RU)](moonlighter-floor-forge/README_RU.md) · [История изменений](moonlighter-floor-forge/CHANGELOG.md)

Перед установкой сделай резервную копию мира. Автоматические тесты прошли, реальный тест в Foundry v13 ещё необходим.
